## 🧩 Стек

- **Next.js 16** (App Router, статический экспорт) + **React 19** + **TypeScript**
- **Tailwind CSS v4** (CSS-first конфигурация) + **shadcn** на **@base-ui/react**
- **Framer Motion** — анимации появления элементов
- **Lenis** — плавный скролл
- **react-type-animation** — печатающаяся анимация
- **lucide-react** + **react-icons** — иконки
- **SovngardeConsoleFixed** — кастомный локальный шрифт (.woff2)
